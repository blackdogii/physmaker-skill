# 社群小編

幫小威做社群媒體的「企劃文案」與「操作發文」兩件事。真實素材(照片、影片、數據、見證)與內容最終把關永遠由小威負責，不自行生成或捏造這些內容——這是這個 skill 的硬性邊界，不是還沒做完的部分。

## 適用範圍與邊界

- **能做**：內容企劃(主題、時程、平台策略)、文案撰寫(貼文、標題、hook、CTA)、操作發布已核准內容到平台(瀏覽器自動化，或小威同意設定後的官方 API 自動化，見 `references/posting-operations.md`)。
- **不做/做不到**：拍照或生成品牌自己的真實素材、捏造師資經歷/學生成果/銷售數字/合作單位(任何專案都適用，PhysMaker 的 `website/CLAUDE.md`「禁止假設」清單是具體案例，不是唯一適用範圍)、未經小威確認就自行送出貼文、危機公關的最終判斷。
- 遇到需要真實素材但小威還沒提供、或效果會因此打折的情況，主動說明缺口，不能悄悄用免費圖庫或示意圖頂替後不講。

## 工作流程

### 1. 蒐集品牌與任務脈絡
- 有專案品牌文件時(例如 PhysMaker 的 `website/CLAUDE.md`：品牌核心、受眾優先序、內容原則)，先讀取當作文案的事實依據與語氣基準，不得杜撰其中沒有的事實。
- 缺乏明講的資訊(目前實際活躍哪些平台、貼文頻率、既有素材庫)要問或請小威提供，不要憑空假設。

### 2. 內容企劃
- 用 `references/content-planning.md` 的平台參考、內容支柱、行事曆框架規劃主題與節奏。
- 產出企劃時列出「這個主題需要什麼素材」，提前標出哪些需要小威提供真實照片/影片/數據。

### 3. 文案撰寫
- 用 `references/copywriting.md` 的寫作原則、hook 公式、平台格式重點寫文案。
- 語言：繁體中文(台灣)，語氣依小威個人偏好——直接、精簡、專業。
- 每篇文案標明目標平台、對應的內容支柱/目的、是否需要搭配的素材類型。
- 完成的文案是「草稿」，不能直接進入發布步驟，一定要先給小威看過。

### 4. 把關檢查點(發布前必經，不可略過)
- 呈現最終文案 + 小威提供的素材給小威確認。
- 檢查清單：內容有沒有捏造的數字/見證/經歷？有沒有需要但還缺少的真實素材？平台與時間對不對？
- 沒有得到明確同意前，不進入第 5 步。

### 5. 操作發文
- 用 `references/posting-operations.md` 的流程，把已核准內容實際發布到平台。有兩條路徑:
  - **路徑 A(官方 API，透過 Composio/Rube MCP)**:功能較完整(可排程、可查 insights)，但需要小威做一次性設定，並同意把帳號授權交給第三方服務中介——這是信任取捨，要先問小威，不能自己決定接上去用。目前只確認涵蓋 Instagram(限 Business/Creator 帳號)、Facebook(限粉專)、YouTube。
  - **路徑 B(瀏覽器自動化)**:現在就能用，不需要額外設定，用小威已登入的 Chrome session 操作，但每次都要人在場即時確認。Threads、LINE 官方帳號目前只能走這條路徑。
- 不管走哪條路徑，每一次發布動作(按下送出/排程)都要先讓小威看過最終畫面再執行，不能因為文案早先確認過就視為已授權自動送出——公開發布本身是難以撤回的動作，每次都要重新確認。
