# 分類詞彙對照表

`category` 欄位只能用下表左欄的值，1:1 對齊 `AI_ENTRY.md` 定義的資料夾，不得自創類別。不確定分類時用 `Inbox`，留給小威人工判斷。

| category 值 | 目標資料夾 | 用途 |
|---|---|---|
| `規則` | `00-系統/` | 核心運作規則（不常變動） |
| `偏好` | `10-個人偏好/` | 小威穩定的個人偏好與限制 |
| `工作流` | `20-工作流/` | 可重複使用的跨專案方法／流程／技術陷阱 |
| `規劃` | `30-長期規劃/` | 已啟用或已確認的長期方向 |
| `決策` | `40-決策紀錄/` | 影響後續工作的已確認決策；未定案先進 `待小威確認.md` |
| `專案` | `50-專案記憶/` | 特定專案的目標、現況、阻礙、下一步 |
| `Skill` | `70-Skills/共享-Agent-Skills/` | 新的可重複技能（需先確認無重複功能） |
| `Inbox` | 留在 `01-收件匣/` | 無法歸類或需要小威人工判斷分類 |

## 搜尋下限（查重最低要求）

寫入前必須依序執行，不得只憑自由關鍵詞搜尋：

1. **讀索引**：依目標資料夾讀對應索引檔——`專案索引.md`（50）、`決策索引.md`（40）、`每日復盤索引.md`（90）。沒有索引檔的資料夾（如 `10-個人偏好/`、`20-工作流/`）因為檔案量小，直接讀該資料夾所有檔案。
2. **展開命中項**：索引指向的筆記若看起來相關，展開讀該篇全文再判斷是否語意重複。
3. **全庫關鍵詞搜尋**：用專案名稱、核心關鍵詞、同義詞再搜一次全庫，涵蓋索引可能沒收錄到的舊資料（例如來源封存區、還沒被索引提及的邊緣內容）。

三步都做完才能判定「沒有重複，可以新增」。
