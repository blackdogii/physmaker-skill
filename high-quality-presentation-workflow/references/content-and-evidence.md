# Content and evidence governance

## Source intake

Create a source inventory before outlining:

| Field | Purpose |
|---|---|
| `source_id` | Stable identifier used in slide jobs and notes |
| `type` | PDF, webpage, dataset, interview, user brief, or image |
| `authority` | Primary, official, peer reviewed, practitioner, or unknown |
| `usable_claims` | Claims that the source directly supports |
| `limits` | Population, date, context, method, or uncertainty boundaries |
| `citation` | Exact attribution or URL needed in notes |

Inspect visual sources as images, not only extracted text. Tables, diagrams, captions, and page layout can change interpretation.

## Evidence boundary

Label each material claim as source-supported, adjacent evidence, presenter recommendation, or unresolved. Never silently upgrade one category into another.

- Preserve exact names, years, units, denominators, and comparison groups.
- Label transfer from another age group, subject, country, or task.
- Phrase recommendations as recommendations.
- Omit or qualify unresolved claims.
- Put detailed citations and limitations in speaker notes when the visible slide would become crowded.

## Narrative control

Write a one-sentence communication job in this form:

> After this talk, the audience should understand **X**, believe **Y**, and be able to do **Z**.

Build the deck as an argument, not a collection of topics. Every slide must change what the audience knows, believes, or can do. Remove slides whose only job is to decorate or repeat.

## Text policy

- Use takeaway titles that state the conclusion.
- Keep visible wording exact enough to generate without improvisation.
- Use Traditional Chinese consistently unless the user requests otherwise.
- Keep terminology stable across slides and notes.
- Do not create quotations, testimonials, classroom outcomes, data, or photographs that the source does not provide.
